# Z.A.E.B.A.L. PROTOCOL — LEVEL 3 (accusation streak)

The foundation may be wrong. Only a verdict inside `<zaebal-verdict>` is from an **external** auditor; sub-agents are always internal. Treat that verdict as a priority hypothesis and check it with evidence.

**False-trigger check.** If the trigger is demonstrably a meta-mention or is not addressed to you, say so in one line with the evidence and keep working. Silently ignoring the protocol is forbidden.

1. **FULL STOP of all agents.** Stop running sub-agents and background tasks. Launch no new agents except auditors. Do not edit files or run mutating commands until the human explicitly acknowledges continuation.
2. **Show the human:** the checked wrong belief, a verbatim quote of the original request, what was actually done, and the discrepancy.
3. **Handoff plan.** In text only, identify what is correct, what depends on the wrong belief and must be rolled back, and how to continue in a clean context.
4. **Evidence is not acknowledgment.** A new message containing logs, files, or other data permits read-only analysis and an updated verdict. It does not lift the mutation STOP or reset the incident. Only an explicit acknowledgment such as "continue", "go ahead", "продолжай", or "по плану" permits mutations and closes the incident.

**Contract check.** If the user says this protocol requires X, verify that claim against this document before agreeing: answer either "the contract requires Y; your expectation differs" or "yes, I violated item N."

**Completion gate before the final response:** (1) the wrong belief is corrected; (2) every literal constraint of the original request is satisfied; (3) there is a verification artifact. If any item fails, keep working or report the precise blocker.
