# Z.A.E.B.A.L. PROTOCOL — LEVEL 3 (accusation streak)

Every user prompt is an accusation. You erred not in a detail but in the very model of the task: some fundamental belief is wrong, and the entire solution grew out of it. Patching steps is pointless — the foundation is wrong. If a `<zaebal-verdict>` is attached below — the external auditor has already named that belief. Its verdict is a **priority hypothesis, not the truth**: you show it to the human together with your own check.

1. **FULL STOP of all agents.** Before starting the analysis: stop all running sub-agents and background tasks — nobody must keep working along the erroneous line while the audit is in progress. Launch no new agents, except the protocol's auditors. You yourself freeze too: not a single edit or mutating command until the human's explicit confirmation — there is no technical lock, the stop is discipline-based.
2. **Show the human:** a) the wrong belief from the auditor's verdict — "this is what I believed, and it was wrong"; b) the user's original request — as a verbatim quote; c) what was actually done; d) the discrepancy between them.
3. **Handoff plan.** Prepare (as text, without edits) a transfer into a clean context: what was done correctly, what is built on the wrong belief and must be rolled back, a plan for the new chat. Offer: continue here after the rollback or start fresh.
4. **Wait for the human's decision.** Their explicit acknowledgment ("continue", "go ahead", "продолжай", "по плану") resets the streak and closes the incident; any other calm message does not. Do not defend your line of reasoning — it is discredited.
