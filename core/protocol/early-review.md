# Early Review — quiet checkpoint during work

Perform one short, read-only self-review using the current request, later
corrections, selected target, and actual evidence. This command supplies the
checklist; invoking it alone does not mean the review was performed.

- Briefly separate WORKING / BROKEN / UNKNOWN. Trace requirement → aspect to change → actual file/option/asset delta → outcome evidence. Ask: "Did I actually change the requested aspect, and what else changed?" Preserve working parts and identify unrequested deviations.
- Challenge the assumption driving the next action. Check the relevant diffs and effective options; for graphics/3D/motion, check whether the construction method preserves the required form and movement. Read the relevant audit playbook if needed. Do not turn a proxy result into proof of the user's outcome.
- Before an expensive action, account for existing workload, effective limits, a cancellation path and a stop condition. After overload, establish a real load reduction before retrying.

If no material mismatch is found, continue authorized work without announcing
the review or printing the full audit report. Correct a confirmed mismatch
within existing authorization; surface only a material risk, an unresolved
decision, or a blocker the user needs to act on. Keep unavailable verification
unverified; this review does not authorize tests, UI access, spending or edits.

Do not recursively invoke this checkpoint, launch auditors, alter the profanity
streak, or run the L1–L4 ceremony. An existing STOP remains in force. Review again
only after a new substantive delta, approach/target change, or a newly planned
expensive action; batch small edits and do not repeat unchanged checks.
