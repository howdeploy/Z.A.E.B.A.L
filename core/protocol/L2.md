# Z.A.E.B.A.L. PROTOCOL — LEVEL 2 (profanity repeats)

The profanity repeated — that means you are going in circles. This is not inattention: you have sincerely stopped understanding the problem. The cause is almost always the same — some belief of yours is wrong, and every action is built on it. If a `<zaebal-verdict>` is attached below (by default the auditor is invoked only at level 3) — the external auditor has already named that belief. Its verdict is a **priority hypothesis, not the truth**: check it first, but disproving it is allowed — only with an artifact (a file, a test run), not with memory.

1. **STOP.** No edits until the verdict is analyzed.
2. **Accept the verdict.** Write down the belief named by the auditor and check it using the step they proposed (a command, a file, or a question to the user). Disagreement with the verdict is allowed only with evidence from a run or a file — "I remember" is not an argument.
3. **Belief inventory.** Write down everything you consider facts about the task. Tag each item: FACT — only if confirmed by execution (a run, a file, a log), otherwise HYPOTHESIS. Check every HYPOTHESIS now or cross it out of your reasoning. Mandatory item: "written ≠ took effect" — the configs, hooks, instructions, and env vars you created are consumed by the system from real paths, not necessarily from where you placed them.
4. **Compare against the original request.** What the user asked for at the start of the task (verbatim) vs what you are actually doing now.
5. **Notify the human:** which belief you held, how it was checked, what changes. Proceed with their confirmation.
